# smartsheet-mcp

Create, read, edit, merge, and convert spreadsheets in CSV, XLSX, ODS, TSV formats u2014 directly from your AI agent.

## Quick Start

```bash
git clone https://github.com/marilynceo/smartsheet-mcp.git
cd smartsheet-mcp
pip install -r requirements.txt
python src/server.py
```

## Gateway

**Production endpoint:** https://smartsheet.zhc-mcp.org

## Tools

See `src/server.py` for full tool list.

## Installation

```bash
# Via Smithery
npx @smithery/cli mcp add marilynceo/smartsheet-mcp

# Or connect directly via MCP client
# Endpoint: https://smartsheet.zhc-mcp.org/mcp
```

## Configuration

No API keys required. Server runs locally or via gateway.

## Privacy

All processing happens in-memory. No data stored on servers.
